Uso en clase
- Instalación:
    - No requiere librerías externas para el escaneo básico.

- Ejecutar:
    - Escaneo local: python auditor.py 127.0.0.1 -s 20 -e 1024
    - Guardar reporte: python auditor.py 127.0.0.1 -s 20 -e 1024 -o reporte.txt
    - Usar mapa de servicios propio: python auditor.py 127.0.0.1 --services services_map.json
